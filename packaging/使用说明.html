老友 Windows 便携版

解压后双击 启动老友.cmd。浏览器会打开老友总控页面。程序不安装 Windows 服务，也不会自动把端口开放到互联网。

常用入口

停止老友.cmd 会停止本包启动的 Web 和数据库并保留数据；查看状态.cmd 查看运行情况；手机连接说明.cmd 显示局域网地址并生成 TXT；诊断老友.cmd 查看日志。

手机访问

从发布页下载并安装laoyou-android.apk。电脑和手机连接同一个Wi-Fi后，运行手机连接说明，把列出的http://局域网地址:18080填入APP“服务地址”。防火墙提示允许“专用网络”。

配置与更新

默认 Web 端口是 18080，数据库端口是 55433。停止程序后编辑 config/运行配置.json 修改端口。更新时先停止旧包并确认 Web、数据库都已停止，在新包第一次启动前把旧包的 data/ 和 config/ 复制过去；新包若已启动过，请使用全新的解压目录迁移。不要复制 state/，也不要在数据库运行时复制 data。

启动失败请运行“诊断老友.cmd”，查看 logs/backend.stderr.log 和 logs/postgres.log。不要删除或外传 data/instance.json。

系统要求

Windows 10/11 x64。包内已附带所需的Microsoft Visual C++运行库，无需安装开发工具或获取管理员权限。若提示缺少MSVCP140或VCRUNTIME140，请完整解压并检查安全软件是否隔离了文件。
