# 首版验收记录

验收日期：2026-09-08。交付目标为本机可运行的业务验收版，不接入真实设备或急救调度。

## 功能对应

| 原需求 | 实现与验收边界 |
|---|---|
| 1 适老化中控屏 | 老人 WebUI，大字、深绿高对比度、大按钮；桌面与412px窄屏检查通过。 |
| 2 你好通通、方言、视频 | 首次启用后持续设备语音唤醒，支持文字等价入口；本地指令助手执行天气、健康、提醒和通话。方言PCM/讯飞接口已实现但未配置账号，未验证真实方言识别准确率。双浏览器真实WebRTC与安卓WebView媒体采集通过。 |
| 3 行为与作息 | 跌倒、深夜徘徊、长静止、睡眠静止、未归规则；模拟观测可指定时间，起床/吃饭/入睡观测用于学习作息。不包含真实摄像头视觉识别模型，观测来源明确标记为模拟。 |
| 4 用药提醒 | 创建、编辑、暂停、删除；语音/文字指令先确认再保存；跨页面定时播报、按提醒ID记录已播状态。服务恢复补建当日漏检计划，迟到用药只提示核对安排。 |
| 5 当日天气 | Open-Meteo实时请求与早间播报；网络失败显示获取失败及来源，不冒充实时温度。 |
| 6 穿戴与健康建议 | 模拟心率、血压、活动与轨迹点记录；健康播报读取最近观测，复用阈值规则；早/午/晚时刻随作息，药物时间不改变。 |
| 7 摄像头开关 | 本机真实预览、周期JPEG快照；关闭二次确认，跨页面采集，远端关闭同步；本机确认关闭时先停止采集。快照明确不是实时监控视频。 |
| 8 异常通知 | 子女/社区/120按类型分流。机构送达为模拟；可模拟失败并重试，记录每次结果。 |
| 9 处理流程 | 确认→开始处理→完成，禁止跳步；时间线保留通知尝试、接收确认、处置和修正。 |
| 10 放心医 | 医疗异常且社区无法协助时创建模拟陪诊工单，申请/接单/完成时间可查。 |
| 11 子女纠正 | 子女可填写原因修正误报；原事件与历史保留；社区不能绕过助手获得此类设置写权限。 |

## 已知接入边界

- 摄像头视觉模型、真实穿戴设备、120、社区外部通知和放心医未接通；当前模拟数据和模拟送达不代表真实识别或真实急救服务。
- 方言服务需要账号凭据及相应授权，尚未做真实方言录音验收。设备语音能力取决于浏览器和系统。
- 子女APP的通知/来电轮询在APP运行期间工作，未接手机厂商后台推送。
- 本次测试为本机/模拟器，未验证实体安卓机及公网NAT/TURN环境。局域网HTTP下浏览器媒体权限可能受安全上下文限制，见README。
- 智能体为本地指令模式，不是开放域大模型问答；医疗数值规则用于演示，不提供诊断或调药。

演示数据包含一条已暂停的示例提醒、模拟穿戴记录和一条已完成处置的模拟事件，便于打开后查看流程；不会因此真实联系任何机构。
