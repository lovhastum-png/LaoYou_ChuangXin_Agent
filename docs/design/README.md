# 界面基准

主屏参考 `home-concept.png`，由内置ImageGen生成，主代理选择为实施基准。用户强调功能优先，不再增加设计方案轮次。

- 总控是老人端，不是密集数据后台。主屏左导航，主区域天气/时间、今日提醒、通通语音入口、视频通话、摄像头状态。
- 背景暖白 `#f6f5ef`、主文字 `#21332d`、主色深绿 `#214f42`、表面白色。保持高对比度，错误/预警同时用文字说明，不仅靠颜色。
- 老人端正文约24px、按钮至少56px触控高度，键盘焦点清楚，支持系统字号与窄屏重排。家属/社区列表可使用18px正文。
- 保留参考图文案与层级；日期、问候、天气、用户姓名和提醒内容必须来自实时状态，不硬编码截图中的样例数据。
- 图标统一Lucide轮廓语义。控件全部真实HTML，不把参考图片当界面背景。
- 用户要求的下游页面按同一颜色、字级、按钮和间距体系延伸；模拟来源、媒体授权失败、未配置语音能力必须可见。
- 原始生成提示：中文老人家庭触屏，1536x1024完整主屏，暖白/深绿，大字、左导航、时间天气、提醒、语音、通话、摄像头控制；无营销区、图表、照片和装饰指标。

交付前由主代理检查参考图与实际浏览器截图、主流程和窄屏布局，记录实际差异与验收结果。
