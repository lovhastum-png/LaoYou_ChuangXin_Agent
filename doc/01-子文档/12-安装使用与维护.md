## 1. 拿到的两个交付件

电脑包包含总控网页、后端和数据库运行环境；APK用于子女或社区手机。日常使用不用安装IDE、Node或Android SDK。手机连接电脑服务，电脑关机或服务停止后，手机无法读取更新数据。

交付件是本地验收版本。真实摄像头预览、视频通话和业务记录可以运行；行为观测、穿戴数据、120与放心医流程为明确标记的模拟接入。不能把界面的模拟送达当成已经联系真实机构。方言服务需要开发者配置服务账号，文本助手可直接使用。

## 2. 电脑首次使用

1. 将电脑压缩包完整解压到自己可写的普通文件夹。不要在压缩包预览窗口中运行，不要放在需要管理员才能写入的系统目录。
2. 双击“启动老友”。首次启动会准备本地数据库，请等到出现可访问地址，再使用自动打开的总控网页。
3. 选择“老人屏”“家属端”“社区端”或“演示管理”，点击“进入老友”。网页会按角色填写演示账号。
4. 需要摄像头或语音时，允许浏览器使用摄像头、麦克风，并确认电脑声音没有静音。

| 身份 | 账号 | 初始演示密码 |
|---|---|---|
| 老人 | elder | Laoyou123! |
| 子女 | child | Laoyou123! |
| 社区 | community | Laoyou123! |
| 演示管理 | admin | Laoyou123! |

电脑上的老人总控使用启动器打开的localhost地址。保持这个页面打开，才能采集快照、接听来电和播放提醒；只开后端但关闭老人网页，无法代替浏览器播放声音。

## 3. 手机安装与连接

1. 将APK发到安卓手机，在手机文件管理器中打开；按系统提示允许本次使用的文件管理器安装应用，再完成安装。
2. 手机与电脑连接同一个家庭或办公局域网。打开电脑启动器显示的手机连接说明，找到电脑局域网地址。
3. 在APP“服务地址”中填写该地址，选择或填写子女/社区账号与密码后登录。手机中的localhost或127.0.0.1指向手机自己，不能代替电脑地址。
4. 首次通话允许摄像头和麦克风；希望收到APP运行期间的通知时允许通知权限。

Windows若询问是否允许网络访问，对可信家庭/办公网络允许“专用网络”。没有提示而手机无法连接时，按第6节排查。不要为了测试直接开放路由器端口。

当前APP没有系统级常驻推送服务。手机杀掉APP、后台被系统冻结或断网时，不保证即时提醒；检查新事件时打开APP并保持服务连通。

### 3.1 电脑与手机不在同一网络时

便携包本身不含公网隧道组件，跨网络访问需要由维护者在源码工作区完成一次搭建（原理与安全要求见[开发者文档15.7](../01-开发者文档.md#157-跨网络访问cloudflare-tunnel)）：

1. 在源码工作区启动老友（`启动老友-预览.cmd`），再双击`启动老友-公网.cmd`；
2. 窗口里会出现一个`https://xxx.trycloudflare.com`地址，等到显示“隧道已就绪”；
3. 手机APP“服务地址”填这个https地址，账号密码照旧；
4. 该窗口必须保持打开，关闭即断开公网入口；快速隧道的地址每次重启都会变，要重新填一次。

该地址在整个互联网上可访问。对外给家人使用前，必须由维护者停用演示账号（`LAOYOU_SEED_DEMO=0`）并改用强口令。

同一家庭或办公局域网内继续使用第3节的局域网地址即可，不必开隧道。跨网络通话在两端都在运营商NAT之后时可能需要TURN中继，属于维护者配置项。

维护者还可以把服务地址**预置进APK**，此时第2、3步都不用做：装上打开，登录页的服务地址已经填好，直接输账号密码即可。预置值必须是固定域名（配好的named隧道），因为快速隧道的地址每次重启都会变。

## 4. 常用操作

| 想做什么 | 操作 |
|---|---|
| 添加用药提醒 | 老人网页进入“用药提醒”→“添加提醒”，填写名称、药品、剂量及每天时间→“保存提醒”。用药时间由用户决定。 |
| 用文字或语音设置提醒 | 点“你好通通”，输入“每天晚上八点半提醒我吃演示药物”。核对识别后的内容和时间，再确认创建。语音能否识别由浏览器及已配置服务决定。 |
| 开启语音唤醒 | 老人首页点“开启语音唤醒”，授权麦克风，再说“你好通通”。没有语音服务或识别失败时可直接点助手输入文字。 |
| 查看天气及健康提示 | 首页看天气，健康记录页看观测；天气及健康播报按保存的作息时间触发。天气降级或模拟数据会标出来源。 |
| 看摄像头画面 | 老人端“安全设置”→“启动本机预览”。家属端读取最近快照；最近快照不是连续实时监控视频。 |
| 关闭摄像头 | 点“关闭摄像头”，核对弹窗后点“确认关闭”。这会停止采集并清除已保存快照。 |
| 与子女通话 | 老人进入“视频通话”或告诉助手“发起视频通话”；子女保持登录，看到来电后接听。结束时点“挂断”。 |
| 处理异常 | 子女/社区进入事件详情，依次“确认收到”→“开始处理”→填写说明→“完成处理”。时间线保存每个节点。 |
| 修正旅游等误报 | 子女在事件详情点“标记误报”，填写原因后保存。原始记录仍保留。 |
| 演示异常规则 | 用子女或演示管理账号进入“家属与社区”，在“注入观测”中选择类型，点“写入模拟观测”。然后查看事件、通知目标和时间线。 |
| 演示陪诊流程 | 对心率/血压异常，用社区账号填写原因后点“社区无法协助”；在模拟陪诊工单中接单、完成陪诊。 |

摄像头授权与实际采集是两步；看到“已允许，尚未采集”时，需要进入安全设置启动本机预览。电脑休眠期间不能提供正常服务，演示时让电脑保持运行。

## 5. 停止、备份与更新

日常关闭时使用电脑包的停止入口，等到停止完成后再移动文件夹或关机。关闭浏览器不会自动关闭后端和数据库。

包内`data/`保存数据库及本包数据库凭据，`config/`保存运行配置，`logs/`保存日志，`state/`保存临时进程状态。备份前完整停止服务，再复制整个`data/`和`config/`到自己的备份位置。不要复制正在写入的PostgreSQL数据文件当成可靠备份。

相同数据库格式的程序更新步骤：

1. 用旧包的“停止老友.cmd”停止服务，保留旧包作为回退来源。
2. 将新包解压到一个新目录，**先不要启动新包**。
3. 将旧包的整个`data/`和`config/`复制到新包，保留新包的`runtime/`、`backend/`、`web/`和`support/`。不要复制旧`state/`。
4. 从新包启动，确认登录、提醒及原有事件仍存在。确认前不要删除旧包，也不要同时运行使用相同端口的两个包。

本流程限同一PostgreSQL主版本、兼容数据库结构的更新；跨主版本或改表必须按开发者提供的迁移步骤操作。尚未提供自动升级器。

## 6. 遇到问题

| 现象 | 先做什么 |
|---|---|
| 双击后没出现网页 | 查看启动窗口/日志中的错误。确认已完整解压且文件夹可写，不要反复删除数据重新安装。 |
| 网页能打开，手机连不上 | 确认电脑服务在运行、两端同网、APP填的是电脑局域网地址及正确端口。检查Windows专用网络授权；访客Wi-Fi可能隔离设备。 |
| 提示账号或密码错误 | 检查账号拼写、大小写及空格，按第2节使用初始演示账号。 |
| 摄像头黑屏或无法打开 | 允许权限，关闭占用摄像头的其他程序，在本机localhost网页重试。确认设备本身有摄像头。 |
| 提醒没有声音 | 检查电脑音量、网页是否打开、语音设置是否开启、提醒时间是否正确；先点一次网页完成浏览器用户交互。 |
| 视频一直等待 | 确认对方登录且已接听、两端网络可达、媒体权限允许。不同网络可能需要额外网络部署。 |
| 手机在外网连不上电脑 | 确认老友已启动、隧道窗口仍开着且已显示“隧道已就绪”，APP填的是当前这一轮的`https://`地址（快速隧道每次启动都会变）。 |
| 公网地址在浏览器报530/1033 | 隧道还没注册到Cloudflare边缘，等窗口出现“隧道已就绪”再访问。 |
| 公网通话接通后约100秒掉线 | 空闲WebSocket被Cloudflare边缘切断，请让维护者检查通话保活逻辑，见[开发者文档第12节](../01-开发者文档.md#12-视频通话与资源释放)。 |
| 记录看起来不同 | 检查是否连接了另一个电脑包、端口或账号；不同包的数据互相独立。 |
| 更新后旧数据不见了 | 先停止服务，找回原包的数据和配置。不要清空或覆盖原目录；让维护人员检查连接位置。 |

求助开发者时说明出错步骤、发生时间、电脑端或手机端，并提供日志中的错误；不要把含密码的配置文件直接发到公开群。

## 7. 开发者维护

先读[主开发者文档](../01-开发者文档.md)和[接口契约](11-接口契约.md)。代码结构、全部业务状态机、权限和测试入口在主手册，本文不重复维护第二套方案。

源码下载包是交付时的工作区快照，包含实际参与交付的修改，不包含Git历史、IDE、数据库、用户配置和Android签名密钥。仓库保留完整历史并作为持续开发的权威工作区；Release另提供Web、后端和Android分端源码，导出脚本为[scripts/export-source.py](../../scripts/export-source.py)。

### 7.1 只开发Web

下载Web源码，先运行Windows便携包，随后在`web/`执行以下命令。需要Node 24.20.0或更新版本、pnpm。PowerShell示例：

```powershell
pnpm install --frozen-lockfile
$env:LAOYOU_DEV_BACKEND='http://localhost:18080'
pnpm dev
```

打开Vite打印的本机地址。`LAOYOU_DEV_BACKEND`同时配置HTTP和WebSocket代理；不设置时默认连接源码后端8000。修改该变量后重启Vite。`pnpm build`执行类型检查并生成`dist/`；电脑分发版需将结果放入包内`web/dist/`，完整重建优先使用封包脚本。

### 7.2 只开发后端

下载后端源码，需要Python 3.11 x64及独立的PostgreSQL数据库。先在数据库中建立应用用户和其拥有的空数据库，再在源码根目录运行：

```powershell
python -m venv backend/.venv
./backend/.venv/Scripts/python.exe -m pip install -r backend/requirements.lock.txt
$env:DATABASE_URL='postgresql+psycopg://应用用户:密码@127.0.0.1:数据库端口/数据库名'
./backend/.venv/Scripts/python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

连接串中的账号、密码、端口和数据库名要换成自己的真实配置；特殊字符需URL编码。应用首次启动会建表并生成演示用户。仅后端源码没有`web/dist`，可访问`/api/health`和`/docs`；要提供完整网页和安卓通话页面，需要另行构建Web并放到同级`web/dist`，或使用完整电脑包。不要直接以测试脚本操作正式数据。

### 7.3 只开发Android

下载Android源码，用Android Studio打开`android/`，安装项目声明的SDK、JDK17，按[主手册构建说明](../01-开发者文档.md#154-前端与安卓构建)配置本地SDK位置和签名文件。运行APP后填写已启动电脑服务的局域网地址。USB模拟器的`adb reverse`仅是开发连通方式，普通手机使用时不需要SDK或adb。

没有原签名密钥的新开发者，可在源码根目录生成自己的本地测试密钥。先确认文件不存在，已有文件不要覆盖：

```powershell
if (!(Test-Path -LiteralPath 'runtime/android-debug.keystore')) {
    New-Item -ItemType Directory -Path runtime -Force | Out-Null
    keytool -genkeypair -keystore runtime/android-debug.keystore -storepass android -alias androiddebugkey -keypass android -keyalg RSA -keysize 2048 -validity 10000 -dname 'CN=Android Debug,O=Android,C=US'
}
./android/gradlew.bat -p android :app:assembleDebug
```

这会产生不同于公开APK的证书，适用于自己的测试安装；不会获得覆盖更新原APK的签名能力。仅修改Web或后端时不需要重签Android。

Android更新需保持applicationId和签名证书一致，并按更新版本提高versionCode；原签名文件由项目维护者保管，不能混进普通用户分发包。换签名通常不能直接覆盖安装，卸载会清除手机端本地数据。数据库与事件记录位于电脑服务端，不能用卸载APP代替数据库维护。

更换已有表结构时需要单独编写迁移；当前create_all只创建缺失表。不要将“替换文件后自动启动”理解为所有未来数据库变更都能自动升级。
