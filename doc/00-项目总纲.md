## 1. 产品定位与当前交付

老友面向独居老人：老人通过电脑上的适老化总控屏使用通通助手、提醒、天气、健康记录与视频通话；子女和社区通过安卓APP查看授权数据并处理异常。Web也提供家属/社区界面，便于同机演示与联调。

当前为本机可运行的首版验收实现。业务记录存入PostgreSQL，视觉行为识别和穿戴观测的输入使用模拟数据，机构通知与放心医服务使用模拟流程；不能把这一边界解释为真实急救系统已经接通。具体功能与边界见[开发者文档](01-开发者文档.md#1-接手路线与产品角色)。

首版代码基线是 `10fbc31`（源码实现来自 `f422654`）。本轮REL-001负责Windows便携包、Android安装包及开箱使用验证，用户同时授权创建[公开仓库](https://github.com/falling-feather/LaoYou_ChuangXin_Agent)，采用MIT协议并在Release分别提供运行包与分端源码。当前执行状态查02，实际交付结果查03。应用自身版本号、依赖版本与交付日期标签分属不同语义。

仓库地址已于2026-09-29迁移：开发主线现为[lovhastum-png/LaoYou_ChuangXin_Agent](https://github.com/lovhastum-png/LaoYou_ChuangXin_Agent)，原`falling-feather`仓库保留为历史只读副本。日常推送、克隆与下载入口一律使用新地址，迁移缘由见[开发历史](03-开发历史.md)。

## 2. 系统组成

| 部分 | 当前方案 | 责任边界 |
|---|---|---|
| 适老化总控WebUI | Vue 3、TypeScript、Vite | 老人操作、设备语音、摄像头与WebRTC媒体 |
| 后端 | Python 3.11、FastAPI、SQLAlchemy、PostgreSQL | 身份授权、规则、调度、事件与持久化 |
| 手机APP | Kotlin、Jetpack Compose | 子女/社区原生界面，通话复用受控WebView |
| 本机运行工具 | PowerShell 7、Python、Gradle、Android SDK | 启停、构建和隔离测试；文件留在工作区 |

具体锁定版本以[依赖配置索引](01-开发者文档.md#15-运行构建与环境配置)中的代码文件为准，不在多份手册重复维护版本清单。

## 4. 工作区与维护约定

所有开发在当前工作区根目录（本机为 `D:\实验室项目\LaoYou_ChuangXin_Agent`）内进行，临时脚本与测试中间文件放 `tmp/`，本机运行依赖与数据库放 `runtime/`。具体执行规则见[AGENTS.md](../AGENTS.md)。运行环境文件、数据库凭据与调试签名不提交Git。

当前没有启用跨用户Codex任务团队或长期worktree对接流程。首版曾使用后端、Web、Android子工作组，主代理负责设计和复核；这段执行事实不等于项目已注册长期责任团队。

文档采用00—03体系；同一事实只有一份原件。修改功能后更新01和必要的接口原件，验收结果归03，任务状态只在02维护。尚未确认的外部接入不自动建立开发任务。
